# Мебель Джованни — лендинг

Одностраничный сайт мебельной компании: мебель на заказ по индивидуальным
размерам в Москве и Московской области. Семь направлений — кухни, шкафы,
гардеробные, прихожие, спальни, санузлы, детские.

## Стек

Никакого. Один самодостаточный HTML-файл: разметка, стили и скрипты внутри,
внешних зависимостей нет, кроме шрифтов Google Fonts. Сборка не нужна —
файл можно открыть двойным щелчком или залить на любой хостинг как есть.

## Структура

```
index.html                  весь сайт: разметка, стили, скрипты
Content/                    изображения
  hero.jpg                  первый экран
  cat-*.jpg                 7 карточек каталога (4:3)
  slide-1…6.jpg             карусель примеров работ (16:9)
  favicon-180.png           иконка для домашнего экрана iOS
ТЗ_Кухни_Джованни_лендинг.docx   техническое задание, на основе которого сделан сайт
```

## Запуск

Открыть `index.html` в браузере. Для публикации — скопировать `index.html`
и папку `Content` в корень хостинга. Настройка сервера не требуется.

## Что нужно заменить до запуска

Все места помечены в коде комментарием `ЗАМЕНИТЬ` — найдите поиском по файлу.

- **Контакты**: телефон, почта, ссылки на WhatsApp и Telegram
- **Реквизиты**: юридическое наименование, ИНН, ОГРН в подвале
- **Цены**: значения «от» в карточках каталога и базовые ставки в квиз-калькуляторе
  (сейчас — ориентировочные рыночные для премиум-сегмента Москвы)
- **Отзывы**: тексты написаны как образец формата, заменить на реальные
  с согласия клиентов
- **Ссылки на отзывы**: карточки компании в Яндекс.Картах и 2ГИС
- **Политика конфиденциальности**: ссылка `#privacy` ведёт в никуда,
  нужна отдельная страница — без неё формы сбора данных нарушают 152-ФЗ

## Интеграция форм

Заявка с любой формы (модальное окно, квиз-калькулятор, блок спецпредложения)
логируется в консоль и открывает WhatsApp на номере 8(926)-185-78-71 с готовым
текстом заявки — посетителю остаётся нажать «Отправить» в WhatsApp. Показывается
экран благодарности. Точка подключения — функция `sendLead()` в начале скрипта:
номер WhatsApp задаётся константой `LEAD_WHATSAPP_PHONE`, а при подключении
бэкенда там же можно добавить свой эндпоинт и цель Яндекс.Метрики.

## Изображения

Фотографии взяты с Pexels (свободная лицензия, коммерческое использование
разрешено, указание авторства не требуется) и служат ориентиром по стилю.
Заменяйте их съёмкой собственных объектов.

Блок «Планировки реализованных проектов» намеренно оставлен на векторных
схемах: рядом указаны сроки, материалы и метраж, поэтому чужие интерьеры
под такими подписями были бы выдачей чужой работы за свою.

## Совместимость

Адаптив от 360px, проверено на 390 / 768 / 1024 / 1240 / 1440 / 1600px.
Последние версии Chrome, Safari, Firefox, Edge, Yandex Browser.
Учтён `prefers-reduced-motion`: автопрокрутка карусели и анимации отключаются.
